# DongDongHai D2iC
The **D2iC** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 26650 cells with a 45mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 45mm |
| Reflector | Ø42×32mm, 10mm opening |
| MCPCB | 20/25mm |
| Driver diameter | 32mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 32.7mm |
| Battery | 26650 |
| Overall length | 150mm |
| Weight | 219g |
| Colours | Black |
| Remarks | USB-C port, 26800 extension tube |
