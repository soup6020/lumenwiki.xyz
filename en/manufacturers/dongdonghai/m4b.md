# DongDongHai M4B
The **M4B** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 21700 cells with a 60mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 60mm |
| Reflector | Ø55×40mm, 10/16.5mm opening |
| MCPCB | 32mm |
| Driver diameter | 32mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 30mm |
| Battery | 21700 |
| Overall length | 165mm |
| Weight | 319g |
| Colours | Black |
| Remarks | Integrated 3A charging in tube |

## Drivers
INeedMoreLumens' open-source [32mm_FET+1_v1.0](https://oshpark.com/shared_projects/8pnFmzGW) Anduril 2 driver was designed for the M4B.

See also: [M4C](/manufacturers/dongdonghai/m4c), [M4D](/manufacturers/dongdonghai/m4d).
