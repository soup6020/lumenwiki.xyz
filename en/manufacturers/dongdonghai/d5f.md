# DongDongHai D5F
The **D5F** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 26650 cells with a 64.5mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 64.5mm |
| Reflector | Ø60×50mm, 10/16.5mm opening |
| MCPCB | 32mm |
| Driver diameter | 32mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 34.5mm |
| Battery | 26650 |
| Overall length | 175mm |
| Weight | 395g |
| Colours | Black |
| Remarks | USB-C port, optional 26105 tube |

## Drivers
INeedMoreLumens' open-source [32mm_FET+1+C_v1.1](https://oshpark.com/shared_projects/wJUqO261) Anduril 2 driver fits the D5F. The [XBY32](/manufacturers/dongdonghai#drivers) driver is also an option.
