# DongDongHai M4C
The **M4C** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 21700 cells with a 60mm head.

> The M4C has been **superseded by the [M4D](/manufacturers/dongdonghai/m4d)**.
{.is-warning}

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 60mm |
| Reflector | Ø55×40mm, 10/16.5mm opening |
| MCPCB | 32mm |
| Driver diameter | 32mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 30mm |
| Battery | 21700 |
| Overall length | 158mm |
| Weight | 319g |
| Colours | Silver / Black |
| Remarks | Discontinued |
