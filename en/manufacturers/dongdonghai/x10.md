# DongDongHai X10
The **X10** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 46950 cells with a 65mm head.

The X10 is a multi-emitter flooder. It is a little smaller than the [F8B (F8)](/manufacturers/dongdonghai/f8b), with more emitters but shallower reflectors.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 65mm |
| Reflector | Shallow multi-emitter reflector |
| MCPCB | 60mm |
| Driver diameter | 47mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 53mm |
| Battery | 46950 |
| Overall length | 188mm |
| Weight | 607g |
| Colours | Not specified |
| Remarks | 1 internal cooling fan, tripod mount, USB-C |

## Emitters
The X10 takes 10 emitters, either 10×7070 or 10×5050.

## Performance
The X10 is a "pure lumen monster". The best builds reach about 120,000 lm. It has more emitters than the [F8](/manufacturers/dongdonghai/f8b), so it is brighter, but its reflectors are shallower, so the beam is floodier.

## Battery tubes
The D6F, D7F, D8, D8DF, F8B and X10 share a 53mm battery tube system. Reported options are 46950, 46120 and 2×46950 tubes, and a 3×21700 carrier.

## Drivers
These hosts take a 47mm driver. Options reported in the thread:
- **XBY47 v4.20**: 50A buck + 350A FET, [Technoman UI](/user-interfaces/technoman-ui), fan controller, 22.5W USB-C charging, powerbank. ([Taobao](https://item.taobao.com/item.htm?id=1056017851318))
- **XBY47 v4.15/4.19**: 40A buck + 300A FET, fan controller.
- Older XBY 30A buck / 300A FET (v3.5k) with working USB-C and click-for-off custom UI. Avoid the older v2.5, which is FET-only.
- To install the [Technoman UI](/user-interfaces/technoman-ui) on the XBY47 v4.2, see [Flashing the XBY47 v4.2 driver](/guides/flashing-xby47-v4-2).
- An Anduril 10A buck / 120A FET driver also fits, but its USB-C port is a placeholder, so charging needs the tube's charging cap.
