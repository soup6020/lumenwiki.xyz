# DongDongHai D8DF
The **D8DF** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 46950 cells with a 85mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 85mm |
| Reflector | Ø80×70mm, 10/16.5/23mm opening |
| MCPCB | 32/50mm |
| Driver diameter | 47mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 53mm |
| Battery | 46950 |
| Overall length | 218mm |
| Weight | 769g |
| Colours | Black |
| Remarks | Cooling fan; 3×21700 and 46120 tubes available |

## Battery tubes
The D6F, D7F, D8DF and F8B share a 53mm battery tube system. Reported options are 46950, 46120 and 2×46950 tubes, and a 3×21700 carrier.

## Drivers
These hosts take a 47mm driver. Options reported in the thread:
- **XBY47 v4.20**: 50A buck + 350A FET, Technoman UI, fan controller, 22.5W USB-C charging, powerbank. ([Taobao](https://item.taobao.com/item.htm?id=1056017851318))
- **XBY47 v4.15/4.19**: 40A buck + 300A FET, fan controller.
- Older XBY 30A buck / 300A FET (v3.5k) with working USB-C and click-for-off custom UI. Avoid the older v2.5, which is FET-only.
- An Anduril 10A buck / 120A FET driver also fits, but its USB-C port is a placeholder, so charging needs the tube's charging cap.
