# DongDongHai M10A
The **M10A** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 26650 (21700 compatible) cells with a 65mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 65mm |
| Reflector | Ø60×18mm multi-emitter optic |
| MCPCB | 50mm (8×5050) |
| Driver diameter | 32mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 34.5mm |
| Battery | 26650 (21700 compatible) |
| Overall length | 148mm |
| Weight | 389g |
| Colours | Black |
| Remarks | USB-C, custom 7070 board |

## Notes
The source thread is inconsistent about the emitter configuration: the reflector column says 10 emitters (5050), the MCPCB column says 8×5050, and the remarks mention a custom 7070 board. Please update this page if you can confirm.
