# DongDongHai D7F
The **D7F** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 46950 cells with a 65mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 65mm |
| Reflector | Ø60×33mm, 3 emitters (7070 PCB) |
| MCPCB | 50mm |
| Driver diameter | 47mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 53mm |
| Battery | 46950 |
| Overall length | 180mm |
| Weight | 530g |
| Colours | Black |
| Remarks | 3×21700 and 46120 tubes available |

## Variants
### D7F Single
Single-emitter version with a Ø60×33mm reflector with a 23mm opening, on the same 50mm MCPCB. Weight unknown. No purchase link is given in the thread.

## Battery tubes
The D6F, D7F, D8, D8DF and F8B share a 53mm battery tube system. Reported options are 46950, 46120 and 2×46950 tubes, and a 3×21700 carrier.

## Drivers
These hosts take a 47mm driver. Options reported in the thread:
- **XBY47 v4.20**: 50A buck + 350A FET, [Technoman UI](/user-interfaces/technoman-ui), fan controller, 22.5W USB-C charging, powerbank. ([Taobao](https://item.taobao.com/item.htm?id=1056017851318))
- **XBY47 v4.15/4.19**: 40A buck + 300A FET, fan controller.
- Older XBY 30A buck / 300A FET (v3.5k) with working USB-C and click-for-off custom UI. Avoid the older v2.5, which is FET-only.
- To install the [Technoman UI](/user-interfaces/technoman-ui) on the XBY47 v4.2, see [Flashing the XBY47 v4.2 driver](/guides/flashing-xby47-v4-2).
- An Anduril 10A buck / 120A FET driver also fits, but its USB-C port is a placeholder, so charging needs the tube's charging cap.
