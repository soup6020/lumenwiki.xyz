# DongDongHai M4D
The **M4D** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 26650 / 21700 cells with a 60mm head.

The M4D replaces the [M4C](/manufacturers/dongdonghai/m4c).

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 60mm |
| Reflector | Ø55×40mm, 10/16.5mm opening |
| MCPCB | 32mm |
| Driver diameter | 32mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 34.5mm |
| Battery | 26650 / 21700 |
| Overall length | 165mm |
| Weight | 365g |
| Colours | Silver / Black |
| Remarks | USB-C, optional 26105 tube |
