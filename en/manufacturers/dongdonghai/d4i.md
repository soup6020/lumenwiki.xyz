# DongDongHai D4i
The **D4i** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 26650 cells with a 60mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 60mm |
| Reflector | Ø55×40mm, 10/16.5mm opening |
| MCPCB | 20/32mm |
| Driver diameter | 22mm |
| Switch | Tail |
| Battery tube diameter | 32mm |
| Battery | 26650 |
| Overall length | 176mm |
| Weight | 328g |
| Colours | Black |
| Remarks | Integrated 3A charging in tube |

## Variants
The thread also lists a multi-emitter D4i with 4 emitters (5050) on a 32mm MCPCB, with otherwise identical specs. No purchase link is given for it.
