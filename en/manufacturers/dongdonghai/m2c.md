# DongDongHai M2C
The **M2C** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 21700 cells with a 40mm head. Kaidomain sells it as the **K2C**.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 40mm |
| Reflector | Ø35×20mm, 7/9/10mm opening |
| MCPCB | 20/25mm |
| Driver diameter | 22mm |
| Switch | Tail |
| Battery tube diameter | 27.5mm |
| Battery | 21700 |
| Overall length | 150mm |
| Weight | 172g |
| Colours | Silver / Black |
| Remarks | Integrated 3A charging in tube |

## Variants
### M2C Triple
A triple-emitter version of the M2C.

| Spec | Value |
|---|---|
| Reflector / optic | Ø35×20mm, 3 emitters (3535/5050) |
| MCPCB | 25mm (3P) |
| Other specs | Same as M2C (40mm head, 22mm driver, tail switch, 21700, 150mm, 172g) |

Sold by Kaidomain as the [K2C-T](https://kaidomain.com/Flashlight-DIY-and-Tools/diy-flashlight-shell-or-flashlight-host/K2C-T-3x-LED-21700-USB-Type-C-Rechargeable-Flashlight-Host).
