# DongDongHai D2GC
The **D2GC** is a [DongDongHai](/manufacturers/dongdonghai) flashlight host for 21700 cells with a 45mm head.

## Specifications
| Spec | Value |
|---|---|
| Head diameter | 45mm |
| Reflector | Ø42×32mm, 10mm opening |
| MCPCB | 20mm |
| Driver diameter | 22mm |
| Switch | Side (e-switch) |
| Battery tube diameter | 28mm |
| Battery | 21700 |
| Overall length | 150mm |
| Weight | Not specified |
| Colours | Silver / Black |
| Remarks | Integrated 3A charging in tube |

## D2G
The **D2G** is the mechanical (clicky) switch version of this host; the D2GC is the e-switch version. Kaidomain sells the D2G as the [K2G](https://kaidomain.com/Flashlight-DIY-and-Tools/diy-flashlight-shell-or-flashlight-host/K2G-21700-USB-Type-C-Rechargeable-LED-Flashlight-Host).

## Notes
- Stock reflector is a 10mm-hole SMO. DDH reflectors are reported to be interchangeable with those of the Convoy C8, C8+, M21A and MantaRay M45.
